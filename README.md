#FlashPeek — A MERN-Based Cognitive Memory Training System

FlashPeek is a flashcard-based memory training and quiz application built on the MERN stack (MongoDB, Express, React, Node.js). It challenges users to memorize visual information under time pressure and then tests recall with progressively harder questions.

## How It Works

1. **Peek Phase** — The app displays an image (or set of images) for 30 seconds.
2. **Quiz Phase** — Once the timer ends, the image disappears and the user answers a series of questions about what they just saw.
3. **Difficulty Ramp** — Questions start easy (broad recognition) and get progressively harder (fine details, ordering, counts), testing the depth and accuracy of the user's memory.
4. **Score & Track Progress** — Results are saved to the user's account so they can track improvement over time.
